# 本地音频目录

如果你拥有与本书匹配、并且有权使用的正版音频文件，可以把音频文件放在这个目录，或直接在章节页点击“选择音频”进行本地播放。

当前页面的本地播放器采用浏览器本地文件选择：

- 音频只在当前浏览器会话中播放
- 不会上传到服务器
- 不会自动提交到 GitHub 或 Cloudflare
- 只有在确认版权和授权后，才建议把文件放入项目的 `public/audio/` 目录

推荐命名方式：

```text
unit-01-track-01.mp3
unit-01-track-02.mp3
unit-02-track-01.mp3
```

当前没有在项目中发现正版 MP3，因此网站不会伪造或填充音频文件。
