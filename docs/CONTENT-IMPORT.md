# 课程内容录入说明

当前课程数据已按 PDF 目录录入 20 个 Unit：

- Section 1 - Networking：Unit 1–4
- Section 2 - Telephoning：Unit 5–8
- Section 3 - Meetings：Unit 9–12
- Section 4 - Presentations and conferences：Unit 13–16
- Section 5 - Interviews：Unit 17–20

每个 Unit 包含：

1. 章节重点说明
2. 4 个原创重点表达与中文解释
3. 1 个章节练习（口语 / 选择 / 改写）
4. 1 个互动角色对话脚本
5. 跟读目标句
6. 本地正版音频选择入口

`src/data/course.ts` 中的学习表达和对话是面向练习的原创教学编排，不是整本书的逐字转载。原书的完整页面、录音文本和 CD 音频不在网站中重新分发。
